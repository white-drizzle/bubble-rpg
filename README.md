# 🫧 泡泡勇者 RPG —— 泡泡堂 × 角色扮演

一个**纯前端、零依赖**的 RPG 风格泡泡堂小游戏：放置水泡炸翻怪物、打木箱爆装备、升级加点、连闯五层迷宫击败暗影魔王，通关后还有无尽深渊模式。

> 无需任何构建工具与后端服务，把仓库部署到 **GitHub Pages** 后即可分享链接给任何人直接游玩。进度自动保存在浏览器 localStorage。

## 🎮 立即游玩

- **本地**：直接双击 `index.html`，或在项目目录运行 `python -m http.server 8000` 后访问 http://localhost:8000
- **在线**：按下方教程部署到 GitHub Pages，把链接分享出去即可

## ✨ 玩法与特色

- **经典泡泡堂规则**：泡泡沿十字爆炸，被石墙阻挡、摧毁木箱；相邻泡泡会**连锁引爆**；被自己的泡泡炸到也会掉血（老玩家的必修课）
- **RPG 养成**：击杀怪物获得经验升级（回满状态+提升属性）、金币结算、死亡只扣 15% 金币，装备经验全保留
- **装备系统**：武器/护甲/靴子/饰品 4 个部位，5 档品质（普通→精良→稀有→史诗→传说），品质越高属性越强；背包可手动装卸与丢弃
- **金币经济**：通关后自动进入「冒险商店」——每层随机 4 件商品以**翻牌卡**形式盖住，点击翻开揭示；物价随层数温和上涨（第 1 关 28 金币也能消费得起）；另有**神秘商人**坐镇商店，每请教一次费用翻倍（30 → 60 → 120 → …），抽取**塔罗牌**获得永久祝福
- **塔罗牌抽卡**：抽卡时进入全屏塔罗牌仪式界面——卡牌飞入、翻面揭示，祝福按品质分为🔵蓝色 / 🟣紫色 / 🟡金色，抽中金色「传说祝福」触发专属特效（金光射线 + 粒子 + 「金色传说！」标题）
- **三个职业**：泡泡战士（血厚防高）、泡泡法师（泡泡多范围大+全场冰冻）、泡泡游侠（高速+冲刺无敌）
- **手机友好**：虚拟摇杆与技能按钮固定在屏幕角落、不随游戏缩放（始终大而好按）；横屏自动切换「HUD 左栏 + 画布 + 技能右栏」布局，画布撑满高度；适配刘海屏安全区
- **五层迷宫 + 魔王战 + 无尽深渊**：史莱姆/哥布林/骷髅兵/暗影蝠各具 AI；魔王会冲刺、投放暗影泡泡、残血召唤小弟；通关后可无限挑战
- **自动存档**：每层通关、商店消费、死亡、退出菜单时自动保存，主菜单可继续游戏
- **零资源依赖**：像素风画面全部用 Canvas 程序化绘制，背景音乐与音效全部用 Web Audio 实时合成，无任何图片/音频文件

## 🚀 部署到 GitHub Pages（三步）

1. **新建仓库**：在 GitHub 上点 `New repository`，例如命名为 `bubble-rpg`（选 Public）。
2. **上传文件**：把本项目所有文件上传到仓库根目录（推荐 git 方式）：
   ```bash
   git init
   git add .
   git commit -m "泡泡勇者 RPG 初版"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/bubble-rpg.git
   git push -u origin main
   ```
   也可以直接在网页端 `Add file → Upload files` 拖拽上传。
3. **开启 Pages**：仓库页面进入 `Settings → Pages`，在 **Build and deployment** 下选择 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，点 **Save**。等待 1~2 分钟后，你的游戏就上线了：

   `https://<你的用户名>.github.io/bubble-rpg/`

   把这个链接发给任何人，点开即玩，无需安装任何东西。

> 💡 小贴士：若仓库命名为 `<用户名>.github.io`，链接会直接是 `https://<用户名>.github.io/`；纯静态文件无需 `.nojekyll`，此仓库结构已完全兼容 GitHub Pages。
